# مُعين — مساعد المستفيدين

تطبيق عربي متجاوب مبني بـ Flask وSQLite، مع بوابة مستفيد، وبوابة موظف محمية، وربط اختياري بـ GPT أو Gemini.

## التشغيل

يتطلب Python 3.10 أو أحدث:

```powershell
python -m pip install -r requirements.txt
python app.py
```

- المستفيد: http://127.0.0.1:5000/
- الموظف: http://127.0.0.1:5000/staff/
- إعداد الذكاء الاصطناعي: http://127.0.0.1:5000/staff/#ai

غيّر المنفذ باستخدام متغير البيئة `PORT`. عند أول زيارة لبوابة الموظف أنشئ الحساب المحلي باسم مستخدم وكلمة مرور من 10 أحرف على الأقل. لا يوجد حساب افتراضي. يُغلق نموذج إنشاء الحساب بعد إتمامه، ويُتاح الإعداد من الجهاز المحلي فقط.

## المتاح

**المستفيد:** الرئيسية، المحادثة مع حفظ وتقييم الردود، السجل والبحث، تفاصيل الخدمات، الطلبات وتفاصيلها وردود الموظف، الإشعارات، مركز المعرفة، اسم العرض وفئة المستفيد والمظهر الفاتح والداكن.

**الموظف:** الدخول والخروج، انتهاء الجلسة بعد 30 دقيقة من عدم النشاط، مؤشرات فعلية، البحث وتصفية الطلبات وتحديث الحالة والرد، إدارة المعرفة بمسودات ونشر وإصدارات، تقارير وتصدير CSV، تغيير الاسم وكلمة المرور، إعدادات GPT/Gemini واختبار الاتصال وإزالة المفتاح.

## ربط الذكاء الاصطناعي

1. افتح بوابة الموظف ثم «ربط الذكاء الاصطناعي».
2. اختر OpenAI / GPT أو Google Gemini.
3. أدخل معرّف نموذج نصي متاح في حسابك ومفتاح API الخاص بالمزوّد. لا ترسل المفتاح في المحادثة ولا تضعه في JavaScript.
4. اضبط حد رموز الرد (256 إلى 4096) والتوجيه الإضافي للأسلوب إن رغبت.
5. اضغط «حفظ وتفعيل الإعدادات»، ثم «اختبار الاتصال المحفوظ». الاختبار يرسل عبارة اتصال قصيرة فقط وقد يستهلك حصة مدفوعة. يلزم حفظ التغييرات قبل الاختبار.
6. وافق من شاشة محادثة المستفيد على إرسال السياق للمزوّد قبل استخدامه. تغيير إعدادات الربط يتطلب موافقة جديدة.

يُشفّر المفتاح بـ Fernet قبل حفظه في قاعدة البيانات. ملف `.ai-encryption-key` هو مفتاح فك التشفير؛ احتفظ به مع نسخة احتياطية آمنة من قاعدة البيانات دون نشره. لا تُرجع واجهات API المفتاح للمتصفح. لا يحمي هذا التشفير من مستخدم محلي يملك كلا الملفين؛ يلزم حماية الجهاز والنسخ الاحتياطية.

يمكن ضبط `OPENAI_API_KEY` أو `GEMINI_API_KEY` في بيئة الخادم بدل حفظ المفتاح. تُستخدم القيمة المحفوظة أولًا ثم متغير البيئة. إزالة المفتاح من الموقع توقف المزوّد وتعيد الوضع المحلي؛ لا تزيل متغيرات البيئة، ويلزم تعديلها من إعدادات تشغيل الخادم عند الرغبة بإزالتها أيضًا.

عند تفعيل مزوّد خارجي يُرسل السؤال وآخر أربع رسائل ومقاطع المعرفة المنشورة ذات الصلة إليه. لا تُرسل الطلبات أو حسابات الموظفين أو أسماء العرض أو مفاتيح الربط ضمن السياق. تحكم سياسات المزوّد التعامل مع البيانات المرسلة. طلبات OpenAI تضبط `store=false`؛ هذا ليس ضمانًا لعدم الاحتفاظ بأي بيانات لدى المزوّد.

الوضع الافتراضي محلي ولا يستدعي خدمات خارجية. لا يوجد نموذج لغوي محلي مثبّت؛ الردود فيه إرشادية محدودة.

## المعرفة وحدود الدقة

- لا توجد لوائح جامعية رسمية ضمن المدخلات؛ المقالات الابتدائية أدلة استخدام للتطبيق فقط. أضف معلومات معتمدة مع مصدرها قبل الإجابة عن المواعيد والشروط الجامعية.
- تُسترجع حتى أربع مقالات منشورة بمطابقة كلمات عربية مطبّعة. هذه مطابقة نصية وليست بحثًا دلاليًا متجهيًا.
- يُطلب من النموذج إرجاع جواب ومعرّفات مصادر. تُرفض المعرفات التي لا تخص المقالات المقدمة، والردود غير القابلة للتحليل. التحقق من معرّفات المصادر لا يثبت صحة كل جملة؛ يلزم تقييم بشري واختبارات دقة قبل الاعتماد.
- المسودات مستثناة من مركز المعرفة وسياق النموذج. الطلبات متصلة بموظف النسخة المحلية دون تكامل مع أنظمة الجامعة الرسمية.

## الملفات والبيانات

- `app.py`: المصادقة والبيانات والطلبات والإحصائيات والمسارات.
- `ai_service.py`: تشفير المفاتيح واستدعاءات GPT/Gemini واسترجاع المعرفة والتحقق من الرد.
- `templates/` و`static/`: الواجهات والتصميم والتفاعلات.
- `instance/assistant.db`: المحادثات والطلبات والمعرفة والإشعارات والحسابات والإعدادات.
- `.session-key`: مفتاح توقيع الجلسات.
- `.ai-encryption-key`: مفتاح تشفير أسرار الربط.

قاعدة البيانات والمفاتيح مستثناة من Git. يمكن استخدام `ASSISTANT_DB` لقاعدة بديلة، و`AI_ENCRYPTION_KEY_FILE` لملف تشفير بديل، و`SECRET_KEY` لمفتاح جلسات بديل.

## التحقق

```powershell
python -m unittest discover -s tests -v
```

تستخدم الاختبارات قاعدة مؤقتة واستجابات محاكاة للمزوّدين، وتتحقق من الصلاحيات وCSRF، وعزل المستفيدين، والردود والإشعارات، والمسودات والنشر، وتشفير المفاتيح، وتنسيق طلبات المزوّدين، وموافقة الإرسال، وأخطاء الاتصال دون تسريب أسرار.

فحص المتصفح في `output/check-portals.cjs` يستخدم Playwright مع Edge وقاعدة مؤقتة. اضبط `PLAYWRIGHT_MODULE` على مسار حزمة Playwright عند تشغيله خارج البيئة الحالية. لا تجري الاختبارات اتصالًا حيًا بخدمات الذكاء الاصطناعي.

## حدود التشغيل

الخادم مربوط بـ `127.0.0.1` ودون وضع التصحيح. هذه نسخة محلية؛ إتاحتها على شبكة عامة تتطلب نشرًا إنتاجيًا وHTTPS وإدارة حسابات وصلاحيات ونسخًا احتياطية وحدود استخدام ومراجعة أمنية إضافية. لا توسّع عنوان الربط قبل استكمال ذلك.

مراجع التكامل: [OpenAI Responses](https://developers.openai.com/api/docs/guides/text)، [Gemini generateContent](https://ai.google.dev/api/generate-content).
